Selecting HTML Elements with JavaScript

Welcome back. In the previous lesson, we used JavaScript to select HTML elements and change their color property. I demonstrated one way of doing this using the method querySelector(), but there are actually many more ways to select elements in the DOM.

I have added a few classes and IDs to our current web page so we can try out different ways of selecting elements inside the DOM.

Selecting Elements by Tag Name

The first method I want to show you is getElementsByTagName(). This method searches the web page for elements with a particular tag name. For example, if we want to get list items (li), and we have three list items inside an unordered list (ul), running getElementsByTagName("li") returns an array containing all three list items.

Expanding this array shows that each list item has many properties you can manipulate. The important distinction with this method, compared to querySelector(), is that the word "Elements" is plural, meaning it fetches all elements with the specified tag name, not just one.

When manipulating one of these elements, for example the third list item, you must select the item from the array using square brackets and the appropriate index. For instance, to select the third item, use index 2. Then setting style.color = "purple" changes the third list item's text color to purple.

In addition to selecting individual elements, you can use array properties such as .length to find out how many elements have a particular tag name. For example, getElementsByTagName("li").length returns 3.

Selecting Elements by Class Name

Similar to getElementsByTagName(), there is getElementsByClassName(), which selects elements based on their class name. For example, if a button element has a class of btn, you can select it with document.getElementsByClassName("btn"). This method also returns an array, even if only one element has that class.

Therefore, to manipulate the element, you must select the first item in the array using index 0. Directly setting properties on the array will not work.

Selecting Elements by ID

The method getElementById() differs because it returns a single element rather than an array. This is because IDs should be unique on a page. For example, selecting the element with ID title returns the single corresponding element. You can then change its content by setting innerHTML.

For example, changing the inner HTML of the element with ID title from "Hello" to "Good Bye" updates the displayed text accordingly.

Using querySelector and querySelectorAll

Another method to select elements is querySelector(), which returns the first element matching a CSS selector. Unlike getElementById() or getElementsByClassName(), you can specify any valid CSS selector string, such as tag names, classes, or IDs.

CSS selectors are the patterns used in CSS to select elements to style. To select by class, prefix the name with a dot (.), and by ID with a hash (#).

With querySelector(), you can combine selectors to target specific elements. For example, to select an anchor tag inside a list item, use li a. To select a list item with class item, write li.item.

When a selector matches multiple elements, querySelector() returns only the first one. To get all matching elements, use querySelectorAll() and access elements by index.

Choosing the Right Method

querySelector() and querySelectorAll() allow complex queries, combining IDs, classes, and tags. In practice, you will often use querySelector() as it's powerful and flexible.

How to change the attributes

Manipulating HTML Element Attributes Now that we have seen how to manipulate the style and the text of an HTML element, the last thing I want to show you is how to manipulate the attributes of any element. Attributes are all the things that get colored in orange in Atom. For example, class is an attribute, the href for an anchor tag is an attribute, and the src for an image is also an attribute. Everything that goes inside the tag, other than the tag name itself, are attributes. We have a link that points towards Google, which takes us to the Google search page. Now, what if we decided to point people towards Bing instead? We can get a list of attributes attached to the element by using document.querySelector("a"), which gets us our first anchor tag that points towards Google. Then, by accessing .attributes, we get a list of all the attributes currently attached to this HTML element. As you can see, there is only one attribute, which is the href. We can retrieve the current value of that attribute by using .getAttribute(). Notice this method is singular, not plural, so it returns the value of a single attribute. We specify the name of the attribute we want, in this case href, and get back that it currently points towards google.com. To change this attribute, instead of .getAttribute(), we use .setAttribute(). This method takes two parameters: the first is the attribute you want to change, and the second is what you want to change it to. For example, we can set it to www.bing.com. Even though the link text still says "Google" because the innerHTML is "Google", if you click on it, it will take you to the new website, Bing. This is a quick and easy way of getting, setting, and seeing what the attributes are for any element you select in the DOM. Key Takeaways HTML element attributes include properties like class, href, and src that are specified inside the tag. You can retrieve all attributes of an element using the .attributes property. The .getAttribute() method retrieves the value of a specific attribute. The .setAttribute() method updates the value of a specified attribute with two parameters: the attribute name and the new value.
